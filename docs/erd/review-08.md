## Proposed: reports and grade legend

PROPOSED / Report page confirmed; grade descriptions proposed

| Grade | Family-facing explanation |
|---|---|
| S | Competition-level mastery: exceptional skill and independence in competition-level challenges; teacher assessment, not an external certification. |
| A+ | Advanced achievement: consistently exceeds module expectations with confident, independent work. |
| A | Strong achievement: meets module expectations confidently and independently. |
| A- | Developing confidence: meets most expectations with occasional guidance. |
| B+ | Steady progress: demonstrates growing understanding with some guidance. |
| B | Developing understanding: builds skills through regular guidance and practice. |
| B- | Building foundations: develops essential skills with close guidance. |

Dedicated Module Reports page: select student and module attempt, enter five criterion grades, write feedback, preview, publish and export PDF. Criteria: coding, building/designing, creativity, problem solving, communication. Include Kodecoon logo, student/module name and legend. Store report -> student_module, report -> criterion grades, and immutable publication -> report revision. Snapshot criterion wording, grade meaning and displayed names. Recommend 'Not assessed' when not observed; not a low grade.
